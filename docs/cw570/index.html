사용법 (실제 fx-570CW와 같은 흐름)
  • HOME: 앱 선택 (Calculate, Statistics, Distribution, Spreadsheet, Table, Equation, Inequality, Complex, Base-N, Matrix, Vector, Ratio, Math Box) → 방향키 + OK
  • SHIFT 후 키를 누르면 금색 기능 (예: SHIFT+7 = π, SHIFT+( = "=", SHIFT+) = ",")
  • 분수 키 = ⌟ (2⌟3 = ²⁄₃, 1⌟2⌟3 = 대분수 1²⁄₃). 결과는 분수·√·π 형태로 표시되고 FORMAT으로 소수/대분수/공학/도분초/소인수분해 변환
  • SHIFT+EXE(≈): 바로 소수로 표시. ▲: 계산 이력, ◀▶: 수식 다시 편집
  • VARIABLE: x,y,z,A~F 불러오기 / Ans 저장. 수식에 A=5처럼 입력해도 저장
  • FUNCTION / CATALOG: d/dx, ∫, Σ, Π, nPr·nCr, Pol/Rec, 쌍곡선, 과학상수, 단위변환(평↔m² 포함) 등
  • TOOLS: 앱별 옵션 (Base-N 진법, 행렬·벡터 정의, 통계 결과·회귀, 스프레드시트 수식 채우기, Math Box 상대도수)
  • 선택형 항목(Inverse Normal의 Tail, Math Box의 주사위 개수)은 ◀ ▶ 또는 OK로 바꿉니다
  • Equation·Statistics 표: 숫자 입력 후 EXE로 확정, 입력이 끝나면 EXE를 한 번 더 누르면 풀이 / 결과(통계는 TOOLS)
  • Spreadsheet: =A1+B1처럼 SHIFT+( 로 "=" 입력 후 수식 (A~E 열은 SHIFT+4~2)
개인 학습용으로 동작을 재현한 앱이며 카시오 공식 제품이 아닙니다. 내부 계산은 배정밀도(15자리)이고, 화면에는 10자리까지 표시합니다. 설정·변수는 이 브라우저에만 저장됩니다. PC에서는 키보드도 사용할 수 있습니다 (숫자, + − * /, Enter, Backspace, Esc, 방향키).
