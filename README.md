# Financial Calculator (아이폰 홈 화면 앱)

금리스왑(IRS·CRS) · 통화선도 · 옵션 이항모형 · PRS · 내재파생 사채(CB·EB·BW) · 공통 금리커브 · 재무계산기(BA II Plus 방식)를
아이폰에서 앱처럼 쓰는 개인용 계산기입니다. 계산 엔진은 **Rust**로 작성해 WebAssembly로 실행합니다.

> 참고용 계산 도구이며, 공식 평가에는 사용을 금지합니다.

## 아이폰에 설치하기

1. 아이폰 **Safari**로 `https://gutereise01-lgtm.github.io/fincal/` 을 엽니다.
2. 아래 가운데 **공유 버튼(네모에서 화살표가 나오는 모양)** 을 누릅니다.
3. **홈 화면에 추가** → **추가** 를 누릅니다.
4. 홈 화면의 **재무계산기** 아이콘으로 실행합니다. 한 번 열어 두면 인터넷이 없어도 실행됩니다.

- 저장한 평가는 이 아이폰 안에만 저장됩니다. 다른 기기로 옮길 때는 앱의 "평가 파일 내보내기 / 가져오기"를 쓰세요.
- 엑셀 내려받기를 누르면 아이폰 공유 시트가 열리고, "파일에 저장"을 고르면 됩니다.
- 새 버전이 올라오면 앱 아래쪽에 "새 버전이 준비되었습니다" 안내가 뜹니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `engine/` | Rust 계산 엔진 (`swap` 스왑·통화선도, `option` 옵션, `prs` PRS, `cb` 내재파생 사채, `curve` 금리커브, `fin` 재무계산기) |
| `docs/` | 아이폰에 설치되는 앱 (GitHub Pages가 이 폴더를 그대로 서비스). `pkg/`는 빌드된 Rust 엔진 |
| `tests/` | Rust 엔진 결과를 원본 엔진과 대조하는 검증 스크립트 |

화면(`docs/index.html`, `docs/app.js`)은 원본 아티팩트의 화면·입력·그래프·저장 코드를 그대로 쓰고,
계산은 모두 `docs/engine.js`를 거쳐 Rust 엔진의 `call(이름, 인자)`로 넘깁니다.
(키패드 화면의 사칙연산 입력 처리처럼 화면 조작에 붙은 부분은 화면 코드에 남아 있습니다.)

## 원본과 달라진 점

- 계산 엔진: Python(Pyodide) + JS 예비 엔진 → Rust(WebAssembly) 하나로 통일. 약 18MB이던 Pyodide가 없어져 엔진이 약 0.4MB입니다.
- 평가 저장: Claude 계정 저장소 → 이 기기 저장소 (원본에 있던 "이 기기에만 저장" 방식).
- 엑셀 라이브러리(SheetJS 0.18.5)를 앱에 포함해 오프라인에서도 엑셀 내려받기가 됩니다.
- PC 앱 전용 기능(인터넷에서 그날 금리 새로 받기, 플로팅 계산기)은 원본 웹 버전과 마찬가지로 동작하지 않습니다. 금리는 앱에 내장된 보관 자료를 씁니다.

## 검증

`tests/run.sh` 는 무작위 입력을 만들어 Rust 엔진 결과를 원본에서 추출한 엔진(`tests/reference/`)과 필드 단위로 대조합니다
(허용 오차 `|a−b| ≤ 1e-9 × max(1, |a|, |b|)`).

- 원본 JS 엔진 대비: 86,764건 중 86,763건 일치 (통과한 값의 최대 차이 2.5e-10)
- 원본 Python 엔진 대비: 1,059건 모두 일치 (최대 차이 1.1e-11)

알려 둘 점 세 가지:

1. **사채 1건 불일치 (0.003%)**: 리픽싱과 액면 중도상환(콜)을 함께 켜면 전환가치 `10000/S×S`와 콜 가격 `10000`이 소수 끝자리까지 같아지는
   노드가 생깁니다. 이때 `≥` 비교가 부동소수점 마지막 자리에 따라 갈리며, 원본도 주가를 1e-15만큼만 바꿔도 같은 폭으로 결과가 바뀝니다
   (Python·JS·Rust가 서로 다른 값을 냄). 모형 자체의 칼날 조건이라 그대로 두었습니다.
2. **옵션 `조기행사 노드 수`**: 가격은 일치하지만, 계속보유가치와 행사가치가 사실상 같은 노드에서 개수가 몇 개 다를 수 있습니다 (배당 없는 아메리칸 콜 등).
3. **PRS 순수 CRR 스텝 수**: 남은 일수 ÷ 트리 간격이 정확히 x.5일 때 원본 Python은 짝수 쪽으로, JS 예비 엔진은 올림으로 반올림해 서로 달랐습니다.
   Rust 엔진은 Python 원본을 따릅니다.

## 직접 빌드하기

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.100
./build.sh          # engine → docs/pkg, 서비스 워커 버전 갱신
./tests/run.sh      # 원본 엔진과 대조 (node, python3 필요)
```
